# 工程目录与存放规范

本工程将目前涉及 ManiSkill 的项目代码与依赖资源集中到一个根目录。新用户可以选择自己的父目录，工程内部继续遵守相同结构。

```text
ARX-ManiSkill/
├── arx_project/                   共享路径、数据契约、模块加载和服务通信
├── configs/
│   ├── modules.json              模块注册表
│   ├── experiments/              当前配置和场景入口
│   ├── pipelines/                可组合的处理阶段
│   ├── environments/             各环境的依赖清单
│   └── path_aliases.json         历史路径的迁移映射
├── modules/
│   ├── maniskill/                仿真接口、执行器和原有基线
│   ├── pipeline/                 场景构造、实验登记和评估编排
│   ├── camera/                   相机标定、投影和深度编码
│   ├── sam3/                     目标分割
│   ├── rayst3r/                  点云重建
│   ├── graspgenx/                抓取生成与夹爪坐标变换
│   ├── curobo/                   运动规划
│   ├── arx_core/                 机器人公共控制和配置读取
│   ├── zerograsp/                原基线与重建对照
│   ├── graspcl/                  候选评分与示教召回
│   ├── claro/                    遮挡处理与任务编排
│   ├── reachability/             可达性分析
│   ├── curobo_adapter/           cuRobo 版本适配
│   └── dinov2/                   视觉特征模型
├── simulation/
│   ├── assets/
│   │   ├── catalog.json          共享资产索引、几何变换与物理参数
│   │   └── models/               所有三维模型、纹理、碰撞网格和共享源库
│   ├── scenes/latest200/         唯一一套当前200场景，按资产ID加载模型
│   ├── robots/arx/               碰撞球和机器人运行配置
│   └── cameras/                  相机参数与挂载配置
├── weights/<method>/             各方法权重和模型配套配置
├── environments/<name>/          独立 Python 环境和编译工具链
├── tmp/<method>/<run_id>/        日志、观测、点云、轨迹、视频、评估、缓存
├── website/                      独立网站及其资源副本
├── tools/                        环境绑定、检查和维护工具
├── tests/                        公共接口和故障测试
└── docs/                         中文工程文档
```

## 存放规则

| 内容 | 存放位置 | 例子 |
| --- | --- | --- |
| 方法实现 | `modules/<module>/` | `modules/sam3/arx_adapter.py` |
| 多模块调用顺序 | `configs/pipelines/` 与 `modules/pipeline/` | 分割→重建→抓取候选 |
| 三维模型及配套资源 | `simulation/assets/models/` | 物体、机器人、桌子、纹理和碰撞网格 |
| 共享资产定义 | `simulation/assets/catalog.json` | 资产ID、相对路径、尺寸、密度、摩擦和坐标变换 |
| 场景 | `simulation/scenes/latest200/` | 200例的资产ID、摆放位姿和冻结初态 |
| 推理、训练和派生权重 | `weights/<method>/` | `weights/graspgenx/gen/` |
| 一次运行的全部记录 | `tmp/<method>/<run_id>/` | `tmp/sam3_graspgenx/run_001/` |
| 共享运行缓存 | `tmp/<module>/<cache_name>/` | `tmp/maniskill/cache/` |
| 已发布的页面、图片、视频、附件 | `website/resources/` | `website/resources/media/` |
| 网站待办数据库 | `website/resources/state/` | 独立于实验记录保存 |

`tmp` 下的第一层是方法或模块名，不能直接放日期或混合实验文件。一次运行内部可以继续划分 `trials/`、`logs/`、`resident/`、`preflight/`、`source/` 等目录。

冻结场景包中为定义、复核该场景而保存的参考观测随数据集放在 `simulation/scenes/`；实际测试重新采集的观测和视频进入对应的 `tmp/<method>/<run_id>/`。

场景目录中不放OBJ、GLB、URDF等三维模型，也不重复保存物体物理定义。多个场景引用同一个资产ID，使用同一份模型文件。机器人和桌子同样从共享资产库加载。当前只保留最新200场景；源资产库中的其余三维模型集中保留，供以后扩充物体使用。具体目录与接口见[场景与共享三维资产整理](场景与共享三维资产整理.md)。

权重只有一个实际存放位置。历史运行里指向权重的文件已改为兼容链接，实际文件归入 `weights/`。新代码直接从公共路径工具取得权重目录。

网站保留发布资源的真实副本，这是独立于实验产物的展示资料。删除实验目录不应联动删除网站副本。

## 命名与路径

代码、配置、方法目录使用英文名；`docs/` 中的说明文档使用中文文件名。根目录的 `README.md`、`AGENTS.md` 保留通用入口名称。

旧工程目录及模块重名入口已经删除，直接使用本工程内的英文模块目录。历史记录保留原始内容，由 `arx_project.layout` 在读取时将旧路径映射到新位置。模块内部对集中资产和权重的引用均指向本工程内部。新模块通过公共路径工具和注册表取得依赖。

账号密钥和云端 API Token 继续保存在用户自己的工程外配置目录，不进入共享包。
