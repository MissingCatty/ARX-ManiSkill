# 场景与共享三维资产整理

当前场景只保留 pipeline 最新的独立采样200例。场景负责描述“加载什么、摆在哪里、机器人从什么状态开始”，三维资产库负责保存模型及其物理定义。同一个物体出现在多个场景时，都加载同一份资产。

## 目录

```text
simulation/
├── assets/
│   ├── catalog.json                    共享资产索引与物理定义
│   └── models/
│       ├── robocasa__lemon__lemon_1/    一个资产ID对应一个模型包
│       ├── ai2thor__book__Book_10/
│       ├── ...                         当前80个物体型号
│       ├── arx_x5_lift/                 机器人URDF与网格
│       ├── workspace_table/             桌子模型
│       └── source_*/                    其余共享源模型库，供后续扩充使用
├── scenes/
│   └── latest200/
│       ├── manifest.json               200例清单
│       ├── object_catalog.json         只保存资产ID与共享索引引用
│       ├── cases/<scene_id>/
│       │   ├── entry.json              物体ID、位姿、初始机器人状态
│       │   ├── state.json              已冻结的初态记录
│       │   └── camera/                 场景参考RGB-D观测
│       ├── frozen_dataset.json         当前冻结清单
│       └── ...                         核验、采样定义与诊断记录
├── robots/arx/                         规划碰撞球与运行配置
└── cameras/                            标定与挂载参数
```

`source_*`按来源收纳尚未单独登记的模型和配套材料，所有场景共用，不按测试场景建立资产副本。当前80个物体已经按稳定资产ID单独归档；机器人、桌子也在同一个`models/`下。纹理、MTL和网格放在所属模型包内，保留相互引用关系。

## 加载方式

共享索引保存模型相对路径、视觉与碰撞网格、缩放、坐标变换、尺寸、密度、摩擦和源文件散列。场景的每个actor只指定资产ID及摆放位姿。例如两个不同场景都使用`robocasa__lemon__lemon_1`时，读取的是同一个模型包。

```python
from arx_project.assets import load_object_catalog, resource_path
from arx_project.layout import read_json
from arx_project.scenes import current_dataset

dataset = current_dataset()
models = load_object_catalog(dataset / 'object_catalog.json')['models']
entry = read_json(dataset / 'manifest.json')['schedule'][0]
target_recipe = models[entry['model_id']]
robot_directory = resource_path('arx_robot')
table_file = resource_path('workspace_table')
```

加载器在内存中把模型相对路径转换成当前工程的实际位置，并核对场景绑定的资产定义散列。实际SAPIEN加载仍使用原有几何变换和物理参数。

## 后续新增与交付

新增物体先放入`simulation/assets/models/<asset_id>/`，再登记到共享索引。场景通过ID引用，不复制模型文件或物理定义。新增运行的观测、候选、轨迹和视频进入`tmp/<method>/<run_id>/`；发布到网站时复制到`website/resources/`。

交付给其他用户时，一并交付`simulation/assets/catalog.json`、`simulation/assets/models/`和`simulation/scenes/latest200/`，保留相对结构。共享索引与场景定义随Git保存，模型大文件单独交付。网站继续使用自己保存的媒体副本。
