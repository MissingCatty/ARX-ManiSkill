# V2指尖近桌接触策略接入

本轮将此前独立实验中的指尖近桌接触策略接入当前871球主线。头部D405→SAM3→RaySt3R→GraspGenX的感知和抓姿保持原样，接触规则由规划器和执行器共同读取。

## 接触范围

| 项目 | 设置 |
| --- | --- |
| 机器人碰撞模型 | 当前871球，球心、半径和机器人几何不变 |
| 可放行的部位 | 两个夹指最前端10毫米 |
| 可放行的接触面 | 桌面上表面 |
| 最大接触深度 | 2毫米 |
| 生效阶段 | 最后接近、闭合；抬升初段只允许退出已有接触 |
| 抬升深度变化 | 接触深度不能增加，物理采样噪声容限0.1毫米且不累计放宽 |
| 其他检查 | 手腕、手臂、夹指主体、桌侧面、其他物体和地面沿用原检查 |
| 仿真物理 | 接触偏移仍为1毫米，质量、摩擦、驱动与成功判据不变 |

本次核对历史保留汇总后，继续采用2毫米上限。已记载的真实指尖新增恢复案例约为1.818毫米，完整依据与记录缺口见[历史碰桌深度与容差选择](历史碰桌深度与容差选择.md)。

## 接入方法

原生碰撞模型先照常检查。抓取终点被拦时，保留原抓姿，在固定预算内补充运动学逆解；每个解均用原生非桌面碰撞检查和真实夹指凸网格检查重新验证。球体碰桌但实际网格没有碰桌的解可以继续；确有接触时，逐项检查指尖区域、桌面边界和2毫米深度。

到预抓取点的路径继续使用原cuRobo规划与优化。最后接近优先保留原生可行路径；需要局部接触时，使用密集验证并按关节速度、加速度和jerk约束定时的局部连接。闭爪后重新读取真实手指关节和接触深度，验证抬升路径，防止用旧的张爪几何或缺失的接触回执放行。

执行录像和轨迹同时记录原规则与新规则。桌面接触不会算成双指夹持目标。独立评估从接触点、法线、深度、末端位姿和物体高度重新计算结果。

## 进入时的夹爪开度

当前 GraspGenX 的 GraspMoE 接口返回每个抓姿的位姿、评分、分支标签，以及目标整体的包围盒。`SweepVolumeParams.jaw_width` 是夹爪全开时的内侧间距，属于模型的夹爪几何输入。ARX 描述中的全开和半开间距分别约为88和44毫米。官方示例另有一个根据物体网格计算闭合目标的几何函数。

当前候选记录的 `width=0.088` 来自 ARX 适配层。预抓取和最后接近均使用全开设置，两个指关节分别命令到44毫米。本轮三项接触验证使用了这个开度。

变开度单列为后续改进。可在每个抓姿的指腹区域内，用目标点云沿夹合轴估算两侧所需间距，并加上进场余量。如果夹持中心有偏移，需分别检查两侧是否有足够空间。确定开度后，先验证收窄夹爪时的扫掠空间，再用同一个开度做接近碰撞检查和仿真执行，到位后闭合。记录开度来源、指关节命令和测量值，再与全开进场做同场景对比。
