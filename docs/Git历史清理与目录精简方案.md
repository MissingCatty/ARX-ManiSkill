## 三、场景参考数据具体是什么

这里的约144.37 MiB实际是`simulation/scenes/latest200/`整个目录的大小，包括当前200个冻结场景的定义和参考观测。三维模型另外存放在`simulation/assets/models/`。

| 内容 | 示例文件 | 用途 |
| --- | --- | --- |
| 相机RGB与深度 | `camera/color.png`、`camera/depth.png` | 核查场景当时的观测、目标位置和深度 |
| 目标真值掩码 | `target_gt.png`、`target_gt_native.png` | 场景构造核验与结果检查 |
