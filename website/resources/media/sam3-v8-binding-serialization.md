# V8配置准备提速

## 这次修改什么

上一轮完整对照中，场景与机器人绑定平均约3秒。每次绑定都要写出约100KB的机器人YAML配置。这次使用已安装的LibYAML C版写出器，减少配置准备的CPU耗时。

原来的初始配置读取缓存继续使用。原版绑定函数、机器人刷新、871个碰撞球、FK、起始碰撞及后续IK和路径检查都照常运行。加速器在独立规划进程内按需启用，默认链路保持原设置。
