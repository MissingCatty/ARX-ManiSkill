# V8：地图索引复用实施

E的目标是利用已有可达性地图减少寻找关节角的耗时。输入仍是GraspGenX原来的抓取位姿，查询得到的关节角可以直接验算，也可以作为IK的初值。

## 查询范围与最终精度分开

原来的0.03弧度约为1.72°。如果拿它限制地图初值的查询范围，很容易把能帮助求解的邻近记录排除掉。因此，本轮分别查询3°、5°、10°范围，比较覆盖情况和实际IK效果。

| 环节 | 位置与角度要求 | 作用 |
| --- | --- | --- |
| 查找邻近初值 | TCP位置相距不超过2厘米；完整朝向分别相差不超过3°、5°、10° | 找到适合开始数值迭代的关节角 |
| 直接使用地图关节角 | 独立FK确认EEF误差不超过2毫米、0.03弧度 | 满足原抓姿精度后，进入当前碰撞和路径检查 |
| IK最后返回的关节角 | 仍按原抓取目标，EEF误差不超过2毫米、0.03弧度 | 保持与原规划组相同的终点精度 |

例如，地图里有一个朝向偏差6°的记录，它可以给10°组提供IK初值。IK随后迭代到原抓姿，再检查误差；并不把这个6°偏差直接带入抓取动作。

## 冻结地图及坐标

使用已有前方180°地图，包含10,559,134组合法关节见证。记录保存TCP43位置、完整四元数朝向、六个关节角与关节裕量，地图不按本轮抓取结果添加数据。

空间索引只常驻位置和原始见证数组，使用完整三维旋转差筛选。查询原点为body4，TCP43还包含工具坐标系的旋转，不能只补一个43毫米的平移。

右臂直接使用body4。左臂按当前实际安装变换映射到相同规范六轴链，使用其原关节状态。原始世界抓姿、机器人站位和候选排名均保持。

| 查询方式 | 计时样本数 | 中位耗时 | P90耗时 |
| --- | ---: | ---: | ---: |
| 直接满足原精度的见证查询 | 10,322 | 0.276毫秒 | 0.402毫秒 |

261个查询点是在每个实际搜索过的手臂序列中取首个和末个候选，去重后得到。新旧8192近邻策略另做32组逐值核对，初值结果相同。128个原地图见证经当前物理URDF复算和自身查询，全部通过。

## 实际IK初值对照

新登记：`tmp/indexed_grasp_planning/index_seed_probe_20261126_01/`。计划使用上述同一261个终点，每组重复3次，共3,132次纯运动学IK调用。该登记在模型加载前因可用显存低于原10,000 MiB门槛停止，实际IK调用0次，3,132次均未执行，停止记录保留。

| 组别 | 初值组成 |
| --- | --- |
| control | 原当前关节状态，加原生采样补到32个 |
| map3 | 当前状态、最多8个3°范围内的不同关节分支，原生采样补到32个 |
| map5 | 当前状态、最多8个5°范围内的不同关节分支，原生采样补到32个 |
| map10 | 当前状态、最多8个10°范围内的不同关节分支，原生采样补到32个 |

每次重置同一求解器的采样序列，轮换各组顺序。没有地图近邻时使用原当前状态和原生采样。记录查询、数据交接和IK合计耗时，保存真正进入LM的32个初值；每个返回分支都按物理URDF独立复算FK和限位。

这一步先判断较宽查询范围能否改善原目标的运动学求解，再决定是否登记完整规划先导。完整规划继续检查当前场景碰撞、预抓取、抬升与路径；原成功是否保留与总请求耗时分别比较。

## 各参考方法对应什么

| 分组或方法 | 本轮作用 | 实施状态 |
| --- | --- | --- |
| B：cuRobo原生批量IK | 一次求解多个原候选 | 完整对照完成，优先保留批量16 |
| C：模型与场景绑定复用 | 减少同一请求内的重复绑定 | 完整对照完成，保留可选 |
| D：EAIK / IK-Geo | 先求几何关节分支，再走当前门控 | 先导完成，当前方案没有提速 |
| E：地图初值复用 | 从已有合法关节见证开始求解原目标 | CPU查询完成；IK对照在加载前显存门控停止，实际0次 |
| VAMP / VAMP-MR | FK和碰撞检查的向量化加速参考 | 尚未实施，不计入B、C、D的收益 |
