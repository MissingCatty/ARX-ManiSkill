# V8上下文复用实施

本阶段是优化计划的C组，单独减少双臂交替搜索时重复绑定模型与场景的工作。B组的207次对照与621个终点复算已经完成，结果见《V8_原生批量IK完整对照结果.md》。

## 怎样复用

原实现左右臂共用一套开放状态和闭合状态上下文，每次轮换需要重新绑定当前手臂与场景。C为左右臂分别保留一套上下文。相同请求内同一只手继续检查下一窗口时，如果测得状态和场景完全相同，就使用已经绑定的上下文。

| 环节 | C的处理 |
| --- | --- |
| 左右臂 | 各自保留开放、闭合上下文，共四个上下文 |
| 纯运动学回退 | 两臂共享同一求解器，保留控制组的调用与随机状态顺序 |
| 复用范围 | 只在同一次完整规划请求内生效，请求结束清空 |
| 输入判定 | 比较完整状态、关节限位、手指开度、机器人变换、场景、目标是否参与及冻结模型版本 |
| 网格 | 每次重新核对网格实际内容；停放臂也参与 |
| 原始回执 | 输出位置必须相同，模型、场景及验证文件必须完整且散列一致 |
| 复用时的检查 | 重置原求解随机状态，再做原精度FK与起始状态碰撞检查 |
| 接触与轨迹 | 继续原871球、TCP43、V2指尖余量、停放臂、局部接近和完整路径检查 |

输入或输出位置变化时执行完整原绑定。回执损坏、输入网格变化与起始检查出现矛盾时停止本批调度。局部接触检查的记录按搜索窗口重新开始。
