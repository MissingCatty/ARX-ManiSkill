# 前方精细地图与新旧流程评估

更新日期：2026 年 11 月 21 日。本轮按“先调整地图、再比较流程、最后决定接入”的顺序开展。地图和离线评估均已完成，抓取执行链路尚未修改，新增物理抓取 0 次。

## 结论与建议

**用户后续明确的接入顺序是：原抓法先做 IK，有有效解就保留；未取得有效解时，再查询地图并尝试小幅修正。** 详见[先 IK 后地图修正流程](先IK后地图修正流程.md)。旧方法允许 20°、30°修正，实际夹持质量没有验证，不宜继续作为默认修正范围。

新版地图保存约 1056 万个前方关节见证。以暂定的 5 mm、3°和相似度 0.6 为门槛，五个历史场景中的 22 个原候选全部未匹配，两个历史成功场景也没有候选通过。该诊断没有前置 IK 分流，只反映直接地图匹配的覆盖情况；不能解释为用户最终流程的失败率或误拒绝率。

后续仅对原 IK 未取得有效解的候选启动地图修正。匹配不足或修正未通过时，记录原因并继续下一个原候选；原位姿已有有效解时直接绕过地图。修正位姿需要重新通过 IK、独立 FK、限位和抓取几何核验。这个后续版本尚未接入执行器。

## 旧图为什么包含机器人后方

旧图确实检查了关节限位。建图先核对 URDF 限位与历史仿真记录，再在上下限内各留出 0.0001 rad 进行采样，并调用原限位检查。此次又逐行复核了旧图全部 3,267,633 个已保存见证，越限数为 0，最小关节余量约 0.000100 rad。

其中 1,476,183 个见证的 TCP 位于 body4 X＜0。旧图没有前方过滤，合法关节组合也可能把末端送到机器人后方。后方点因此不是“没有检查关节限位”的证据。

新版将任务范围明确为 body4 X≥0，排除了 6,218,082 组朝后样本。此处限制的是末端位置范围，未额外限制夹爪朝向，也未把各臂段全部限制在前半空间。

独立核验抽取了 512 个新图见证，用另一条 URDF FK 实现复算，最大位置差约 0.000131 mm，最大朝向差约 0.0000111°。完整已保存见证另有前方与限位逐行复核。这里只证明登记模型下的运动学见证，不包含自碰撞和场景碰撞保证。

## 新旧流程具体比较什么

| 环节 | 旧流程 | 本轮评估的新流程 |
| --- | --- | --- |
| 查询入口 | 先围绕原抓法生成 0°、±5°、±10°、±15°、±20°、±30°建议，再查询地图排序 | 本次独立诊断对原抓法直接查地图；最终接入另要求先 IK、失败后才进入地图分支 |
| 地图作用 | 软排序，最近见证离得很远也可继续后续求解 | 位置、朝向与综合相似度都满足门槛才算匹配 |
| 抓取位姿改动 | 名义双指接触线不动，但夹爪可大幅旋转 | 匹配位姿的偏差受门槛限制；是否仍符合物体夹持几何需要另验 |
| 未匹配 | 没有严格邻近门槛，继续搜索 | 记录匹配不足；本轮只统计，不淘汰或执行原候选 |
| 最终可达证据 | IK 解、独立 FK 和限位核验 | 地图关节见证、实际升降变换、独立完整机器人 FK 和限位核验 |
| 夹持质量 | 原轮未执行修正抓取 | 本轮未执行抓取；小改动也不能替代接触面检查 |

本轮评估参数为位置差≤5 mm、朝向差≤3°、综合相似度≥0.6。这些是用于判断地图是否够密的暂定参数，没有写入抓取执行配置。

综合相似度定义为：先将位置差除以 5 mm、朝向夹角除以 3°，把两项平方相加，乘以 −1/2 后取指数。相似度越接近 1，位姿越接近；它不是抓取成功概率。位置和朝向同时有偏差时，综合门槛会进一步收紧。

检索对旋转使用完整三维旋转夹角，并处理四元数正负等价。先用少量近邻获得距离上界，再取出该上界内所有可能更优的点作精确比较，避免只看固定数量位置近邻而漏掉朝向更匹配的点。

“新图＋旧软排序”只比较排序结果，没有再次运行 IK 或路径搜索。原旧流程对于成功控制会保留已通过的原抓法，表中的 −20°不表示旧轮实际修改过控制抓法。旧轮三个问题场景保留的完整离线方案继续有效，不能把本轮的匹配数直接与旧轮规划成功数当成同一个指标比较。

为核对是否是检索程序漏查，另做了 64 次新图已存见证回查，均以相似度接近 1 找回；在 5000 点子集上，16 次查询与全库穷举结果一致。故障检查覆盖四元数符号、固定近邻截断、阈值跳过、前方范围、升降适配、非法变换和越限见证。

## 哪个流程更合适

| 判断维度 | 本轮判断 |
| --- | --- |
| 控制位姿改动 | 新流程更清楚，位置与朝向都有明确上限；旧轮 20°、30°改动不宜作为默认 |
| 取得运动学见证 | 旧轮局部搜索已有验证结果；纯地图吸附在当前小阈值下无匹配，不能据此替换旧执行器 |
| 保留原成功场景 | 最终流程先 IK，有有效原位姿解就保留并绕过地图；本次 0/22 不能视为该流程的误拒绝 |
| 抓取质量 | 两种修正都缺少物理夹持对照，尚不能宣称哪种实际抓得更好 |
| 地图粒度 | 四倍采样与 5 mm 统计格仍不足以支撑全六维严格吸附；后续应评估任务相关朝向的加密，而非只缩小格子 |
| 确定的接入顺序 | 原抓法先 IK；未取得有效解时再查询地图与小幅修正；修正后重验 IK、FK、限位和抓取几何；无合格修正则继续下一个候选 |

下一步按[先 IK 后地图修正流程](先IK后地图修正流程.md)接入和评估：原抓法能解时保持原位姿，只对原 IK 未取得有效解的候选比较有无地图修正的恢复情况。需要修改时保留名义接触关系，并复核实际接触面与指腹覆盖。若进一步加密地图，应在独立开发输入上构建、冻结后在留出输入上评估，不能把测试目标求解后写回地图，再用同批目标证明地图覆盖良好。
