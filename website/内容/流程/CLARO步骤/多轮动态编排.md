## 尚未接入的闭环

| 需要补齐的能力 | 作用 |
| --- | --- |
| 操作后重新生成语义场景图 | 识别新露出的物体及关系变化 |
| 将实际工具回执反馈给 VLM | 让下一步决策参考真实执行结果 |

| 多次选择与定位挡物 | 支持需要搬走多个物体的场景 |
| 明确失败与终止条件 | 保留失败和未执行项，防止无限重试 |
