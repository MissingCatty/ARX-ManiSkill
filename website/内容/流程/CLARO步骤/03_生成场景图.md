## 输入与处理

Qwen4-Max 读取无标注的腕部 RGB，调用 survey_scene，返回 YAML 格式的场景概述及可见物体列表。每个物体具有独立编号，避免两只杯子或两块积木被混为一个实例。

| 输出字段 | 含义 |
| --- | --- |
| obj_id、name、desc | 实例编号、名称及颜色形状描述 |
| point_norm | 物体可见区域上的二维归一化点，顺序为行、列 |
| position_description | 当前图像中的位置描述 |
| relations | 相邻、前后、上下或遮挡等关系 |

## 真实输出节选

下面是 I0069 保存结果中两个节点的节选，实际场景图还有小绿积木和黄杯。

```yaml
objects:
  - obj_id: 1
    name: green cup
    point_norm: [0.63, 0.41]
    relations: [[next_to, 2]]
  - obj_id: 2
    name: blue block
    point_norm: [0.48, 0.49]
    relations: [[next_to, 1], [behind, 1]]
```
