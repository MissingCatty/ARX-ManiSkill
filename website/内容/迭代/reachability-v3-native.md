## 方案改动

让升降关节和右臂一起规划到预抓取点。到达后固定升降高度，再由右臂靠近物体、闭爪并抬起。

## 抓取过程

腕部彩色和深度图 → ZeroGrasp候选与原生后处理 → 升降与右臂联合规划 → 固定高度完成抓取。

## 实验设置

| 设置 | 说明 |
| --- | --- |
| 起始高度 | 升降关节从45.2 cm开始，底盘固定。 |
| 参与规划的关节 | 升降关节与右臂六个关节共同规划到预抓取点，共七个自由度。 |
| 靠近物体后 | 固定规划选定的高度，由右臂完成最后接近、闭爪和短距离抬升。 |
| 测试场景 | 开阔桌面、靠近桌边、稀疏混放、中度杂乱各40个，共160个场景。 |
| 观测与候选 | 每个场景重新拍摄腕部彩色和深度图，使用ZeroGrasp原生后处理候选。 |
| 接近与抬升 | 预抓取点距抓取点8 cm，计划抬升3 cm；夹爪动作参考点沿末端前向偏移43 mm，记为TCP43。 |
| 成功条件 | 物体实际抬高至少1 cm并保持3秒，两侧手指接触物体，动作到位且接触检查通过。 |

## 结果分析

152个场景进入抓取执行，116个成功，36个在执行或持物保持环节失败，其中18个未达到抬升保持要求。另有7个场景没有得到可执行方案。

有1个场景在执行前的记录核对中被拦下，没有发出机器人动作，结果表中单列为未执行。
