## 方案改动

将升降关节的初始读数设为45.2 cm，抓取过程中保持这个高度，由右臂六个关节完成接近、闭爪和抬升。

## 抓取过程

腕部彩色和深度图 → ZeroGrasp候选与原生后处理 → cuRobo右臂规划 → 接近、闭爪、抬升并保持物体。

## 实验设置

| 设置 | 说明 |
| --- | --- |
| 升降高度 | 升降关节读数固定为45.2 cm，桌面高50 cm；这个读数表示升降位置。 |
| 参与规划的关节 | 右臂六个关节，升降和底盘在抓取过程中固定。 |
| 测试场景 | 开阔桌面、靠近桌边、稀疏混放、中度杂乱各40个，共160个场景。 |
| 观测与候选 | 每个场景重新拍摄腕部彩色和深度图，使用ZeroGrasp原生后处理候选。 |
| 接近与抬升 | 预抓取点距抓取点8 cm，计划抬升3 cm；夹爪动作参考点沿末端前向偏移43 mm，记为TCP43。 |
| 成功条件 | 物体实际抬高至少1 cm并保持3秒，两侧手指接触物体，动作到位且接触检查通过。 |

## 结果分析

153个场景得到完整规划，其中111个抓取成功，42个在执行或持物保持环节失败。另有7个场景没有得到可执行方案。

抬升保持高度不足有21例，是本轮最多的失败原因，主要损失发生在规划通过之后。
