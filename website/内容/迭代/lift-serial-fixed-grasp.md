## 方案思路

先让机械臂停在经过检查的安全姿态，再单独调整升降高度。升降到位并停稳后，重新获取相机图像和外参，随后固定升降位置，由右臂完成抓取。

这个方案把升降和机械臂的动作分成两段，前一段通过实际状态检查后再开始下一段。

## 这样安排要处理什么问题

- **两套执行机构的响应差异。** 单独完成升降并确认停稳，再执行机械臂轨迹，避免近距离绕障时还要依赖升降与手臂同时到位。
- **升降带来的整机移动。** 升降前检查双臂、头部和躯干的活动空间，并确认另一只手的持物状态及周围障碍。
- **相机位置变化。** 升降后按当前高度更新相机在世界中的位置，重新观察目标和桌面，再生成抓取候选。

## 执行顺序

| 步骤 | 动作 | 进入下一步的条件 |
| --- | --- | --- |
| 1．安全停靠 | 将右臂移到安全停靠姿态，检查另一条臂和持物情况 | 停靠动作到位，双臂及头部有足够活动空间 |
| 2．选择高度 | 在合法升降行程内选定本次抓取高度 | 检查整个升降过程中的双臂、头部和躯干碰撞 |
| 3．单独升降 | 手臂保持停靠姿态，只执行升降动作 | 实际高度达到目标并保持稳定 |
| 4．重新观察 | 更新相机外参，重新拍摄腕部彩色和深度图 | 目标、深度和场景状态可用于本次规划 |
| 5．固定高度规划 | 保持升降位置，用ZeroGrasp生成候选，cuRobo规划右臂动作 | 抓取、接近和抬升方案通过碰撞及路径检查 |
| 6．抓取与保持 | 右臂接近、闭爪并短距离抬升物体 | 满足双指接触、动作到位和抬升保持要求 |

## 计划沿用的设置

| 设置 | 计划内容 |
| --- | --- |
| 抓取链路 | ZeroGrasp原生后处理候选，由cuRobo规划右臂 |
| 升降与手臂的关系 | 升降阶段手臂保持停靠姿态；抓取阶段升降位置固定 |
| 工具参考点 | 沿末端前向偏移43 mm，记为TCP43 |
| 接近与抬升 | 沿用8 cm预抓取距离和3 cm计划抬升 |
| 成功条件 | 物体实际抬高至少1 cm并保持3秒，两侧手指接触物体，动作及接触检查通过 |
| 场景选择 | 计划与固定高度方案使用相同的桌面布局，具体场景和批次在测试前登记 |

## 待验证内容

先验证安全停靠、整机升降碰撞检查、升降到位与稳定判定，以及升降后的重新观察。随后分别统计升降阶段通过数、抓取规划通过数、实际抓取成功数和整次任务耗时。

升降目标高度、速度限制、稳定等待门槛，以及另一只手持物时的处理方式，在实现和正式批次登记中确定。
