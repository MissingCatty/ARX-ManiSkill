## 版本定位

以 ZeroGrasp 生成抓取候选、cuRobo 负责机械臂规划，作为 ARX 桌面抓取的主版本。该版本提供 GraspCL 候选扩充和 CLARO 移障重抓的对照。

## 技术流程

腕部 RGB-D 与目标掩码 → ZeroGrasp 生成六自由度抓取姿态 → 原生后处理 → 按 ARX 开爪几何与实际桌面检查候选并截断过深的进场 → cuRobo 检查逆运动学、碰撞和路径 → 执行接近、闭爪与短抬升。

候选过深时沿接近轴按 2 毫米步长后退，找到仍覆盖目标点云且开爪不碰桌的姿态。评测要求实际抬高至少 1 厘米并连续保持 3 秒，规划抬升目标为 3 厘米。

## 实验结果

| 指标 | 已验收结果 |
| --- | ---: |
| 初始规划通过 | 133/200 |
| 实际成功抓取 | 105/200（52.5%） |
| S5 部分遮挡场景成功 | 4/40 |

失败主要出现在抓取端点或接近、抬升段的可达性和场景碰撞检查。分布局数据见 [200 例同场景对照](/results/#benchmark)。

## 参考文献与方法

- ZeroGrasp 利用零样本形状重建和点云生成抓取候选。本项目采用原生后处理后的位姿，并用 ARX 几何进行执行前检查。[ZeroGrasp 论文与方法](/papers/zerograsp/)
- cuRobo 提供 GPU 并行的逆运动学、碰撞检查与轨迹规划。[cuRobo 论文与方法](/papers/curobo/)
- 本地结果来源为 ManiSkill 的《截断与小幅抬升前后对比》与《两条管线200例成功场景分布》，验收批次为 `arx_physical_table_parallel_20261118_01`。
