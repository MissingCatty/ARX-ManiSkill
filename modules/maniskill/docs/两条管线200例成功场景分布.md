# 200 例成功场景分布

两条基线来自 `arx_physical_table_parallel_20261118_01`，MPC 组来自 `arx_graspcl_mpc_200_20261119_03`。三组使用同一批 200 个场景，每类 40 例。 [三轮复测与数据来源核查](GraspCL数据来源与可达性核查.md)

- ZeroGrasp：腕部 RGB-D → ZeroGrasp 原生后处理 → cuRobo → ARX 执行。
- GraspCL：腕部 RGB-D → ZeroGrasp 原生后处理 → GraspCL 冻结示教召回与重评分 → cuRobo → ARX 执行。
- GraspCL＋MPC：采用同一冻结示教库，cuRobo 使用非严格朝向规划，ARX 通过 MPC 跟踪全局轨迹并在接近末段做腕部精调。

沿用本批次成功判定：目标抬升 3 cm，物体实际抬高至少 1 cm 并连续保持 3 秒，同时满足原实验的接触、收敛等检查。成功率以全部登记场景为分母，初始化和规划失败也计入。
