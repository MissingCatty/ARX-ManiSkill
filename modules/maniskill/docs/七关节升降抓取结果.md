# 七关节升降抓取结果

## 实验设置

右臂六关节＋原升降joint4联合规划至固定8cm预抓取点，随后固定所选升降高度，执行接近、闭爪和名义3cm短抬升。初态仍为45.2cm，底盘不动，腕部重新采集RGB-D。两法各160个原S1–S4场景，复用上一轮冻结的24正例＋4负例GraspCL库。

原右臂碰撞模型、场景物理、质量、驱动和成功判据保留；补齐原躯干／左臂凸碰撞部件的完整竖直扫掠检查。新增升降1mm收敛门槛。实际成功仍须物体抬高至少1cm并保持3秒，通过原双指接触、手臂收敛及禁止接触判定。
