# CLARO-ARX 复现计划

目标是在现有 ARX 抓取链路中验证**夹走一个挡物 → 重新观测 → 重抓目标**，看它能救回多少因遮挡或碰撞而失败的场景。

## 复现原则

每次设计方案或实现模块，先查 [CLARO 论文 PDF](CLARO论文.pdf) 正文与补充材料。论文明确给出步骤、接口或参数时，优先按原文复现，并在对应章节注明依据。论文未交代的细节，再结合 ARX 和现有链路设计，写清依据、选择和验证办法。原文做法与本地实现的改动分别记录，方便对照。

云端 VLM 优先使用现有阿里云 Token Plan 支持的图像模型。第二步先用 `qwen4-max` 复现论文的工具调用流程，并在章节中记录模型替换与输入视角适配。

各模块的讨论、实施方案和衔接方式放在各自的章节目录中。图片、视频和附件统一放在对应章节的 `resources/` 里，章节文档使用相对路径引用。方案文件创建后更新本表。

先用碰撞记录选出的固定挡物建立清障对照，测清障本身的收益。复现论文的 VLM 挡物选择后，再比较两种选择方式的效果。
