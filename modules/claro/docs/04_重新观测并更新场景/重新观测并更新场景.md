# 重新观测并更新场景

CLARO 在操作改变场景后重新感知，规划器下一轮读取当前场景图像。补充材料也记录了夹走挡物后重新调用 `survey_scene` 的情形，因为移障可能露出原有场景图里没有的物体。本轮跟踪任务中已知的原目标积木，用第 01 步同样的腕部视角和仿真实例分割来测量移障收益。 [CLARO 论文 PDF，第 3、12、21 页](../CLARO论文.pdf)

| 步骤 | 实施方式 | 进度 |
| --- | --- | --- |
| 1. 接续移障状态 | 在独立仿真实例中重建第 03 步撤离后的机器人关节和场景物体实测姿态，静置后核对偏差。 | **已完成。** 重建误差检查通过。 |
| 2. 回到相同观测位 | 保持夹爪张开，用包含绿杯新位置在内的完整场景重规划腕部观测轨迹。到位后核对相机内外参和各物体位置。 | **已完成。** 501 个规划复核点均通过，726 个执行采样均无机器人接触。 |
| 3. 重新采集并比较 | 采集同帧腕部 RGB、毫米深度、实例掩码和相机参数，将原目标掩码内的有效深度投影到 `body4` 坐标系。比较移障前后的像素数、有效点数和遮挡率。 | **已完成。** 原目标的 3226 个掩码像素均有有效深度。 |
| 4. 更新规划碰撞场景 | 用新观测时的物体实测状态刷新 cuRobo。检查绿杯、原目标、其他物体及桌面均在更新后的场景中，并保存第 05 步所需输入。 | **已完成。** 四个物体、桌面和地面均已核对，重抓输入已保存。 |

本轮场景为 `I0069`。原目标是 `073-e_lego_duplo` 积木，已移开的挡物是 `065-i_cups` 绿杯。上一步实例已退出，接续使用实测静止姿态，初始速度从零开始。 [移障交接状态](../03_夹走并放下挡物/resources/I0069_移障验证04/final_state.json)

## 同视角结果

| 指标 | 移障前 | 移障后 |
| --- | ---: | ---: |
| 原目标可见像素 | 2490 | 3226 |
| 原目标有效深度点 | 2490 | 3226 |
| 原目标遮挡率 | 22.8% | 0.0% |

重采时相机内参一致，位置与原观察位相差约 0.001 毫米。遮挡率用目标在完整场景中的可见像素与在同一视角下隐藏其余物体时的像素数计算。绿杯移开约 18.3 厘米，原目标积木的位置变化小于 0.01 毫米。更新后的场景继续包含绿杯，使用它的实测新姿态。
