# ARX 可达性与能力地图

独立的离线可达性先验工具。以当前右臂六关节、TCP43 和原关节限位为基础，保存经过原静态碰撞检查的 FK 见证，并统计位置及朝向覆盖。

地图用于可视化、候选排序参考和 IK 初值检索。未覆盖表示未知，不作为候选否决条件；当前杂物和路径仍由执行链路在线检查。当前工具不启动仿真实例或机械臂动作。

首版已完成，见 [结果说明](docs/可达性地图/结果说明.md)、[交互三维地图](docs/可达性地图/resources/首版_01/交互可达性地图.html) 和 [实施方案](docs/可达性地图/实施方案.md)。网站的“配置与核查”也可直接打开。所有新增入口均在 `工具/`，不会改写原有 benchmark 或默认执行器。

后续工作见 [未来改进计划](docs/未来改进计划.md)，包括先完成固定高度对照、再试升降联合规划，以及后续的可达性引导抓取位姿局部修正。
