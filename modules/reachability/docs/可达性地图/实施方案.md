# ARX 可达性地图实施与验收

## 目标与范围

生成当前 ARX 右臂的朝向相关可达性地图，找到更容易工作的区域，并为 IK 提供已知可行关节解。当前升降高度约 0.22 米，机械模型、关节限位、TCP43 和原碰撞策略保持不变。

采用 DLR 的关节采样、正运动学及体素表示思路，并补充朝向格覆盖、限位余量、雅可比条件指标和关节解索引。参考：[DLR Reachability Maps](https://github.com/DLR-MO/reachability_map)、[ROS-Industrial REACH](https://github.com/ros-industrial/reach)。

| 步骤 | 目标 | 实施方式 | 入口／产物 | 进度 |
|---|---|---|---|---|
| 1. 冻结模型 | 确认坐标和模型一致 | 读取原 URDF、原碰撞球、TCP43 及已保存基座与静态桌地配置，校验源散列 | `产物/首版_01/原始依据.json` | 已完成，源散列不变 |
| 2. 建图 | 为覆盖区域保存正向见证 | 固定种子 Sobol 采样约 419 万组关节角，原 checker 筛查关节及静态碰撞，保存 TCP 位姿和关节解 | `关节见证.bin` | 已完成，3267633 组静态有效见证 |
| 3. 统计 | 区分密度、朝向覆盖与姿态质量 | 2 厘米查询格、5 厘米概览格；统计完整 SO(3) 格及朝下 60° 方向子集 | `精细体素统计.npz`、`概览体素统计.npz` | 已完成，精细 185926 格／概览 13688 格 |
| 4. 查询 | 为 G／H 检索 IK 初值 | 按位置与旋转距离搜索，保留不同关节解；未覆盖返回未知 | `工具/查询地图.py` | 已完成，7 项接口检查通过 |
| 5. 离线验证 | 验证地图与查询是否可信 | 独立 URDF FK／雅可比、随机见证抽检，以及已有 G／H 的原场景 IK 对照 | `独立模型核验.json`、`查询验证_01/查询对照结果.json` | 已完成，133 点原初始化与地图初值各通过 20 点，新增通过 0 |
| 6. 展示 | 能直观看到较好的工作区域 | 三维交互图、桌面高度切片、常见朝下方向覆盖与区域表 | 同目录 `resources/首版_01/` | 已完成；网站“配置与核查”已接入 |

结果、适用范围及使用入口见 [结果说明](结果说明.md)。本轮没有修改默认抓取执行器，没有新增实际抓取；地图初值尚未证明改善历史困难点的 IK 通过数。

## 指标含义

- 覆盖率是**体素内已经观察到的朝向格比例**。关节采样并非每个位置均匀的朝向试验，该比例不解释为真实 IK 成功概率或抓取成功率。
- 原始采样次数单独显示，不用其代替朝向覆盖。较高限位余量和较好的雅可比条件是附加质量指标。
- 地图表达在 `body4` 坐标系，查询点统一为当前 `action_tcp43`。EEF 输入先使用原 TCP 转换。
- 静态地图含原桌面、地面与原机器人碰撞策略。场景中的当前杂物不烘焙进通用地图；最终 IK、整机碰撞和轨迹有效性仍由原场景检查。
- 建图只使用机械模型和独立关节采样，不把已有失败／成功案例的关节解直接加入地图。已有 G／H 仅作后续查询验证。
- 所有计算为离线数学与碰撞模型查询，新增物理抓取数为 0。
