# ARX机器人左右两臂可达性空间特征

更新日期：2026年11月23日。

ARX左右两臂各自形成一片向机器人前方展开、同时覆盖本侧和中央区域的运动学空间。右臂向机器人右侧延伸得更远，左臂向左侧延伸得更远；机器人正前方有较大的共同覆盖区域。两条臂的高密度核心分别偏向自己的肩侧，其中大部分也能被另一条臂覆盖，但两臂各自最密集的部分只局部重合。

本文描述当前机器人模型下的位置覆盖、关节配置采样密度和朝向特征，并结合最近的桌面抓取距离实验解释这些特征的意义。

## 1．坐标与模型关系

所有空间位置统一使用body4坐标系。body4位于随升降机构运动的躯干部分：X轴正方向朝机器人前方，Y轴正方向朝左侧，Z轴正方向朝上。本文统计机器人前方180°范围，即TCP的X坐标大于或等于0。

在当前完整机器人URDF中，两条臂都是六轴结构。除肩部安装位置外，关节轴、连杆变换和关节角度限位一致。左右肩在body4坐标系中均位于前方约6厘米、上方约2.45厘米，左右方向分别为左侧25厘米和右侧25厘米，肩部间距为50厘米。

两臂具有明确的对应关系：给两条臂设置同一组对应关节角时，左臂TCP比右臂TCP向左平移50厘米，前后位置、上下位置和末端朝向相同。因此，当前模型中左臂的完整空间分布可以由右臂分布沿Y方向平移50厘米得到。

这一关系已经通过完整URDF链条比对，以及512组关节配置的左右臂独立正向运动学复算核对。两侧统一采用距离EEF原点43毫米的TCP及相同工具坐标定义。

## 2．左右两臂的覆盖范围

目前地图的前方采样点具有以下外包范围，单位为厘米。范围取自已保存的合法关节配置，不同高度和朝向对应的实际覆盖轮廓会有所变化。

| 方向 | 右臂TCP采样范围 | 左臂TCP采样范围 |
| --- | --- | --- |
| 前后X | 前方约0至84.4厘米 | 前方约0至84.4厘米 |
| 左右Y | 右侧约103.4厘米至左侧53.4厘米 | 右侧约53.4厘米至左侧103.4厘米 |
| 上下Z | body4下方约56.7厘米至上方82.9厘米 | body4下方约56.7厘米至上方82.9厘米 |

右臂的明显特征是向右侧具有更大的外侧覆盖，而左臂向左侧具有对应的外侧覆盖。两条臂都能够跨过机器人中央区域，覆盖另一侧的一部分位置。

这些覆盖区域是有厚度的三维空间。越接近前方和侧方的外缘，覆盖轮廓越容易收窄，可出现的关节配置与末端朝向也更受限制。前伸距离、侧向位置和高度共同决定一个抓取目标处于空间内部还是接近边缘。

升降机构改变body4在世界坐标中的高度，整片手臂空间也随之上下移动。相对于body4，两臂的六轴运动学空间形状保持不变；相对于桌面，能够使用的高度截面会发生变化。

## 3．高密度区域的分布特征

下文的密度表示：在相同的合法关节角采样方法下，有多少关节配置把TCP送进同一块空间。高密度区域意味着这里聚集了更多关节配置，这些配置可以具有不同的末端朝向。

右臂的高密度核心主要靠近右肩一侧，左臂的高密度核心相应靠近左肩一侧。两条臂的密度分布具有相同形状，但峰值位置随肩部位置相隔50厘米。

在当前桌面附近的高度带，按5厘米空间格统计，高密度格的采样加权中心大致为：右臂在body4前方16厘米、右侧24厘米；左臂在前方16厘米、左侧26厘米。两者高度均约在body4下方17厘米。这些中心用于描述密集区的位置，区域本身会向前、向两侧和上下延伸。

当前升降关节为45.2厘米时，body4原点位于桌面上方约22.2厘米，近侧桌沿位于body4前方约23.1厘米。由此可以看出，纯运动学密集区的一部分位于机器人与桌沿之间的近身空间；桌面抓取使用的是这片区域向前延伸、与桌面上方工作空间相交的部分。

对具体抓取动作，末端朝向与位置需要一起考虑。同一个位置可以有一些朝向对应的关节解，而另一些朝向未必能解出。中央共同覆盖区域为左右臂提供了选择空间，每条臂还需要核对目标要求的具体抓姿。

## 4．双臂共同覆盖区域与高密度核心

两臂共同覆盖的中央区域较大，左右两侧分别保留各自更擅长覆盖的外侧空间。在桌面附近，两臂覆盖空间中约六成属于共同覆盖区域；在整个前方三维空间中，这个比例约为56%。

下面的范围分别来自5厘米和2厘米两种空间粒度。高密度区域按各比较范围内空间格采样数的第75百分位划定，包含同分格。“桌面附近”采用body4的Z为−25至−10厘米这一高度带，与之前距离实验的地图对照范围一致。

| 空间特征 | 整个前方空间 | 当前桌面附近高度带 |
| --- | ---: | ---: |
| 每条臂的位置覆盖空间中，属于双臂交集的比例 | 55.7%至56.9% | 59.1%至60.5% |
| 右臂高密度区域中，也被左臂覆盖的比例 | 72.2%至74.9% | 88.6%至90.7% |
| 左臂高密度区域中，也被右臂覆盖的比例 | 76.5%至79.9% | 85.7%至89.1% |
| 一条臂的高密度区域中，同时也是另一条臂高密度区域的比例 | 22.2%至24.3% | 20.2%至22.7% |

这几组数字体现了两个不同的特征。第一，在桌面附近，右臂和左臂的大部分高密度区域都处于共同覆盖空间内。第二，一个位置同时被两臂覆盖时，它可能对其中一条臂具有更高的配置密度；两条臂都属于高密度的部分，大约只占各自高密度区域的五分之一。

这里的共同覆盖表示左右臂分别能够覆盖同一片位置，每条臂可以采用自己的末端朝向。左右两条臂对某个完整抓姿的可达情况，要分别核对该抓姿的位置和朝向。

2026年11月25日补充了共有区与单臂独有区的直接比较。在桌面附近，5厘米格的共有区内，右臂自身每格平均配置数为1467个，独有区为556个，约2.64倍；已覆盖朝向数分别为284种和183种，约1.55倍。左臂结果相近。2厘米格复核后，两臂配置密度之比约2.4至2.5，朝向覆盖之比约2。详细方法和结果见[共有区域与单臂独有区域的可达性比较](共有区域与单臂独有区域的可达性比较.md)。

## 5．与当前桌面抓取实验的联系

在53个原规划失败场景、318个距离位置的分析中，候选所在区域的地图密度与纯IK通过比例呈明显正相关，排序相关系数约为0.93。物体逐步靠近后，53个场景的地图密度与纯IK通过比例全部提高，其中39例恢复了初始轨迹规划。

在131个已经通过规划的距离位置中，实际选中抓取目标所在的5厘米空间格有101个属于双臂共同覆盖区域，约占77.1%；另外30个仅在当前右臂地图中被覆盖。这说明中央共同覆盖区域对当前任务很有价值，右臂本侧的空间也同样能够完成抓取规划。

实验中仍有5例在进入较密集区域后，能够解出的IK比例达到约38%至61%，无碰撞抓取终点却仍为0。这部分与夹指、手臂和桌面或邻物之间的几何关系有关，后续规划需要单独处理这些碰撞。

在使用这些空间特征时，目标偏右可优先考察右臂，目标偏左可优先考察左臂，中央区域则可以比较两条臂对具体抓姿的适应情况。站位与升降高度用于把目标带入更合适的空间截面；具体动作沿用原抓姿先做IK、再检查碰撞和路径的顺序。
