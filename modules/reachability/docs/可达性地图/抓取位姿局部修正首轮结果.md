## 本次具体修改了什么

从已完成七轴批次中读取原生后处理及 ARX 几何截断之后的候选，复用原腕部 RGB-D、掩码、机器人状态和场景。没有重新生成候选、替换相机或训练模型。

修正只绕候选的名义双指接触线转动，试探 0°、±5°、±10°、±15°、±20°、±30°。候选的名义 P1/P2、宽度和接触中点保持不变，末端朝向及 TCP43 对应的 EEF 位置随转角变化。真实接触位置与夹持质量尚未实测。

输入合法性检查保留原开爪球模型的桌面余量和可见目标闭合区交集，并记录实测指腹范围中的观测点。地图使用邻近完整位姿见证作软排序，未用空白体素否决候选，也未沿用旧 22 cm 地图的静态碰撞通过标签。

## 地图引导修正的具体方法

**当前实现先生成同一组局部修正建议，由地图给这些建议安排检查顺序，再通过七轴求解取得有效关节见证。** 修正角度来自预先确定的离散集合，地图负责优先检查哪个方向；本轮尚未实现连续位姿优化或修正网络。

| 步骤 | 实际做法 | 产物或判断 |
| --- | --- | --- |
| 1．读取原抓法 | 读取原生后处理及 ARX 几何截断之后的抓取候选，以及本次观测对应的机器人状态、目标点云和相机标定 | 保存原位姿、来源、宽度和名义 P1/P2 |
| 2．生成修正建议 | 绕候选局部 +Y 所对应的双指夹持轴转动；取 0°、±5°、±10°、±15°、±20°、±30° | 名义 P1/P2、接触中点与宽度保持不变，朝向改变；按 TCP43 换算出的 EEF 位置随之变化 |
| 3．检查输入几何 | 检查开爪球模型对桌面的余量、目标点是否进入闭合扫掠区，以及实际指腹范围内是否存在观测点 | 本轮几何准入要求桌面余量非负、闭合区支持点数大于零、指腹区观测点数大于零；不等于已经验证真实夹持质量 |
| 4．转换并查询地图 | 将每个 EEF 目标转换到采集时的 body4 坐标系，再转换成地图使用的 action_tcp43 位姿；先检索位置邻近的 2048 个已保存见证，再结合朝向比较 | 得到邻近关节样本及其位置、朝向误差；地图未覆盖保持未知 |
| 5．给建议排序 | 对每个建议计算下述地图排序分数，分数小的先检查；同分时优先较小转角，再按原候选编号 | 形成建议的检查顺序；本轮没有把地图关节样本注入 IK 初值 |
| 6．核验位姿可达性 | 对排在前面的建议求解升降＋右臂七关节，并独立复算 FK 与关节限位 | 只有取得满足原 2 mm／0.03 rad 容差的关节见证，才标记该终点位姿已验证可达 |
| 7．单列下游结果 | 将有见证的建议继续交给现有碰撞与路径检查 | 下游通过情况单独保存，不替代终点可达证据 |

### 地图分数怎样计算

地图检索首先以位置和朝向距离为主，并附加较小的关节余量、与当前关节状态距离的偏好，选出一个邻近见证。本轮对修正建议的最终排序使用这个见证的两项位姿误差：

`地图排序分数 = 位置误差 ÷ 0.020米 + 朝向误差 ÷ 0.35弧度`

| 量 | 含义 |
| --- | --- |
| 位置误差 | 建议的 action_tcp43 位置与所选地图见证 FK 位置之间的三维距离 |
| 朝向误差 | 两个位姿旋转之间的夹角，同时考虑完整朝向 |
| 0.020 米与 0.35 弧度 | 平衡两项距离的归一化尺度；最终 IK／FK 验收仍使用 2 mm／0.03 rad |
| 分数较小 | 该建议更接近本轮检索到的地图见证，优先安排核验 |

原抓取生成器的分数保留在记录中，本轮没有对修正后位姿重算抓取质量分数，也没有把它加入上述地图排序公式。

### 与固定顺序局部修正相比，地图具体改变了什么

两组使用相同的转角集合和几何准入条件。固定顺序组先检查原角度，再从小到大检查转角；同一幅度按原候选编号排列，并先负角、后正角。地图组按地图分数排列这些建议。地图分数只参与地图组的顺序决策。

例如 I0052 的记录如下：

| 方法 | 实际检查顺序 | 本轮结果 |
| --- | --- | --- |
| 固定顺序局部修正 | 0° → −5° → ＋5° → −10° | 前三个建议在抓取终点检查处被拒绝，−10°取得完整离线方案 |
| 地图引导局部修正 | 优先检查 −30° | 第一个建议取得完整离线方案，并保存了独立 FK 与限位核验通过的关节见证 |

本轮执行器在取得终点关节解后还会继续检查下游，因此这里及下方的调用次数统计到“取得完整离线方案”为止，不是单独的首次运动学解计时。两组共用的预处理已经计算了地图分数，固定顺序组不使用这些分数；这不是两套完全独立运行的端到端耗时对照。

### 当前地图的适用范围

本轮仍使用原六轴、body4 坐标系下保存的地图见证，在线核验则使用七轴模型。地图查询时尚未显式搜索不同升降高度，旧静态场景的碰撞通过标签也未沿用。因此这张图在本轮只提供软参考。

以 I0052 的 −30°建议为例，所选地图见证与目标的位置差约 233.8 mm、朝向差约 10.27°，排序分数约 12.20。这两个数是地图邻近程度，不是最终输出的 FK 误差。最终七轴求解得到的关节解已通过独立 FK 核验。后续需要适配升降变化下的地图查询，提升地图本身与当前七轴任务的匹配程度。

当前阶段的判断是：局部角度修正能产生带有效关节见证的位姿；地图在这三个开发场景里帮助更早检查到有效建议。是否能在留出场景、固定预算下取得更多可达位姿，仍需验证。
