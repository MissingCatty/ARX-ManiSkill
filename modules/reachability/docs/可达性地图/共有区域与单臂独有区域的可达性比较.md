# 共有区域与单臂独有区域的可达性比较

2026年11月25日。

**按现有运动学地图，双臂共有区域整体具有更高的配置密度，也覆盖更多末端朝向。** 分别统计右臂和左臂，桌面附近共有区的单臂配置密度约为独有区的2.4至2.6倍，已覆盖朝向数约为1.6至2倍。

## 比较方法

使用冻结的10559134条前方关节见证，以及当前完整机器人URDF。坐标为body4，工具为TCP43。桌面附近取空间格中心Z位于−25至−10厘米的高度带，分别采用5厘米格和2厘米格。

共有区要求同一位置格同时被左右臂覆盖。右臂独有区要求右臂有覆盖而左臂未覆盖，左臂独有区定义相应对称。每条臂分别统计自身的配置样本数和去重后的朝向数，位置格等权。

朝向沿用原地图的1152个显示统计格。这里的朝向数表示一个位置格内已观测到的不同朝向格数。关节配置来自限位内的Sobol采样，配置数用于描述空间密度。比较结果给出覆盖趋势，具体抓取位姿继续进行运动学、碰撞和路径检查。

## 桌面附近，5厘米位置格

每条臂有757个位置格属于共有区，494个位置格属于该臂独有区。

| 指标 | 共有区每格平均 | 该臂独有区每格平均 | 共有区与独有区之比 |
| --- | ---: | ---: | ---: |
| 右臂关节配置样本数 | 1466.53 | 555.97 | 2.64倍 |
| 左臂关节配置样本数 | 1464.05 | 559.78 | 2.62倍 |
| 右臂已覆盖朝向数 | 284.41 | 182.94 | 1.55倍 |
| 左臂已覆盖朝向数 | 284.78 | 182.37 | 1.56倍 |

按同一高度带全部已覆盖格的配置数第75百分位定义高密度格，阈值为每格1054个样本。右臂共有区中37.5%的格达到高密度，独有区为5.9%；左臂分别为36.9%和6.9%。

中位数也有相同方向。右臂共有区每格865个配置、277个朝向，独有区分别为585个和211.5个。左臂对应867个和275个，独有区568.5个和204个。

## 桌面附近，2厘米格复核

每条臂有11522个共有格、7962个独有格。位置格缩小后，每格计数随体积减小，比较采用同一粒度下的两区域之比。

| 指标 | 共有区每格平均 | 该臂独有区每格平均 | 共有区与独有区之比 |
| --- | ---: | ---: | ---: |
| 右臂关节配置样本数 | 98.96 | 40.31 | 2.46倍 |
| 左臂关节配置样本数 | 98.50 | 40.97 | 2.40倍 |
| 右臂已覆盖朝向数 | 71.29 | 35.70 | 2.00倍 |
| 左臂已覆盖朝向数 | 70.99 | 36.13 | 1.96倍 |

两种粒度的方向一致，共有区的配置和朝向选择均更丰富。按5厘米格统计整个前方空间、不限桌面高度时，共有区每格配置数约为独有区的1.75至1.94倍，已覆盖朝向数约为1.33至1.43倍。

## 这对当前抓取链路的意义

共有区的位置往往同时处在两条臂较充足的运动学覆盖范围内。即使只用右臂，该区域仍显示出更多配置和朝向选择。具体某个点的某种朝向是否适合抓取，还要看该抓姿的实际关节解，以及夹爪、手腕、桌面和邻物的几何关系。
