# 独立采样场景方案

重新生成200个场景。继承原40类、80个型号、五类布局各40例，以及每例的目标和挡物身份；位置和朝向重新随机采样。

| 项目 | 固定规则 |
| --- | --- |
| 采样区域 | 桌面靠机器人一半，世界X为−0.7245至−0.12米；桌面中央80厘米宽，世界Y为−0.40至0.40米 |
| 位置分布 | 区域内均匀采样；桌边组使用近侧真实桌沿，物体外缘距桌沿9–11厘米 |
| 目标朝向 | 五组统一使用−180°至180°的连续随机平面朝向 |
| 明显越界 | 根据URDF连杆长度推导宽松外侧上限；只有整个目标包围盒都越过上限才排除 |
| 物理和观察 | 检查稳定落桌、初始无机器人碰撞、物体不重叠、头部完整视野、有效深度和可见像素 |
| 布局 | 保留五组的挡物数量和间隔；遮挡组真实遮挡20%–40%，其余组不超过15% |
| 随机种子 | 主种子2026112223；每例由主种子与场景ID的SHA256确定，生成前登记 |
| 冻结 | 全部200例通过几何和图像核验后，保存场景清单、所有位姿及图片的散列 |
| 事后诊断 | 冻结后统一检查三个准备位置的静态IK，成功、失败均保留，不修改场景 |
| 抓取测试 | 本轮保持停止，物理抓取预算0 |

构造阶段不读取旧位置和IK通过结果，也不调用IK、规划器、SAM3或抓取模型。几何准入失败可以按同一登记规则继续采样；冻结后的IK失败不能触发重新摆放。

旧的IK准入批次已按要求清理。新场景单独保存到`experiments/diverse_object_scenes/datasets/diverse200_geometry_20261122_01/`，完成后更新统一场景入口和网站已有的200场景图集，继续标出目标物体。
