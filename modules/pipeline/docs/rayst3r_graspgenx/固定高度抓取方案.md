# RaySt3R＋GraspGenX固定高度抓取测试

2026年11月22日：用户已停止本轮，并要求删除本轮结果。原测试数据与录像已清理；后续先为头部感知链路重新构造200个场景。本文件保留实现方案。

本轮先测抓取效果，RaySt3R推理加速建议已单独存档，保留当前网络、精度和22个总视角。

| 项目 | 本轮设置 |
| --- | --- |
| 测试场景 | 原固定45.2厘米实验的160个非遮挡场景，四种布局各40个 |
| 尝试次数 | 每个场景一次，共160次；不自动重抓，不继承旧成绩 |
| 初态 | 沿用45.2厘米批次初态、桌高50厘米和原场景；保留已有观察手臂动作 |
| 主视角 | 头部D405，沿用已核验的45°向下安装和逐设备标定 |
| 分割 | SAM3，输入目标文字和头部RGB；同一文字候选按模型分数选择 |
| 补全 | 当前RaySt3R，输入头部RGB-D、SAM3掩码、内参 |
| 抓法 | GraspGenX原生GraspMoE，512个扩散样本加dense OBB候选、原生评分；不加旧五例的30°筛选，不另行修改候选位置或朝向 |
| 夹爪条件 | 从现有ARX夹爪几何计算扫掠体；生成器位姿按现有标定换算到EEF及TCP43 |
| 规划执行 | 原六轴cuRobo；升降固定45.2厘米；8厘米预抓取、3厘米抬升 |
| 碰撞策略 | 沿用原实际桌面策略；检查开爪、接近路径及实测闭爪后抬升 |
| 成功判据 | 物体实际抬升至少1厘米，连续保持3秒；同时满足双指接触、收敛及无禁止接触 |
| 记录 | 头部原图、SAM3叠图、输入点云、原生抓法、候选池、规划拒绝阶段、完整轨迹、第三人称和头部视频 |

先用开发柠檬检查头部标定、组件预热和候选到规划的完整接口，不执行预检抓取。通过后运行160个登记场景。普通抓取失败如实计入；资源或接口故障停止调度并保留现场。

规划场景沿用原实测物体碰撞资产。目标实例真值掩码单独保留供评估，SAM3、RaySt3R和GraspGenX不读取真值目标掩码或完整物体网格。历史腕部画面准入不用于筛选新的头部观测。

结果分别统计初始规划通过率、实际抓取成功率、未执行数量以及分阶段失败原因。

实现入口：`experiments/rayst3r_graspgenx/run_suite.py`。每次执行先生成独立登记，冻结后不原位修改。
