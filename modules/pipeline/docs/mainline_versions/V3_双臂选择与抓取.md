# V3：左右臂选择与抓取

2026年11月25日。

## 本版做什么

在SAM3＋RGB-D点云＋GraspGenX＋cuRobo主线中接入左右臂。一次观测生成同一组世界坐标抓取候选，分别检查左右臂能否完成到预抓取点、最后接近和抬升。选定一条臂后，由该臂执行闭合与抓取，另一条臂保持原位。

## 执行流程

| 步骤 | 实施方式 |
| --- | --- |
| 观测与生成 | 使用当前头部D405、SAM3、RaySt3R和GraspGenX，候选世界位置和朝向保持。 |
| 检查右臂 | 按GraspGenX原生排序检查，取得第一条通过完整规划的候选。 |
| 检查左臂 | 使用相同候选池与规划规则，绑定左臂实测关节、夹爪和末端。 |
| 选择执行臂 | 先比较可执行候选的原生排名；同一候选两臂均通过时，选择到预抓取点关节位移较小的一臂。 |
| 准备开度 | 预检初态到每指44毫米的张开过程，包含目标和停放臂碰撞检查；选定后原地张开并检查实际开度，再开始手臂运动。 |
| 执行抓取 | 用选中臂接近、闭合，读取真实闭合状态后重新规划抬升，保持3秒。 |
| 验证记录 | 记录两臂各自规划结果、选臂原因、实际末端、手指接触、停放关节状态及双视角视频。 |

## 双臂如何绑定同一个求解器

完整机器人URDF中，两臂的六轴运动链、关节轴和限位相同，左肩沿body4的Y方向比右肩平移50厘米。程序先核对这一关系，再将选中臂的实测状态绑定到同一个六轴求解器；世界坐标中的物体、抓姿与障碍物位置保持。

该关系已用32组关节状态、包括手指和末端的各连杆变换核对。左臂物理执行仍写入left_joint11至16、left_joint17和18，不向右臂关节发送左臂轨迹。

## 碰撞球与停放臂

左右臂采用同一套当前871球局部参数，对应关系如下。球心和半径逐项一致，左臂经连杆名归一化后的参数哈希与右臂相同。

| 右臂连杆 | 左臂连杆 | 每侧球数 |
| --- | --- | ---: |
| right_link21 | left_link11 | 26 |
| right_link22 | left_link12 | 115 |
| right_link23 | left_link13 | 97 |
| right_link24 | left_link14 | 36 |
| right_link25 | left_link15 | 24 |
| right_link26 | left_link16 | 89 |
| right_link27 | left_link17 | 258 |
| right_link28 | left_link18 | 226 |
| 合计 | 合计 | 871 |

16组关节状态下，全部球心的独立左右臂FK核对一致。选中臂使用871球；停放臂的原始碰撞网格按当前实测关节变换后加入cuRobo场景，初始规划、局部指尖检查及抬升都保留它。

左右指尖的顶点范围相同，但原始凸分解不同：右侧每指19块，左侧每指1块。局部桌面接触检查分别读取实际左右手指的分解。两臂接触、停放关节漂移或记录故障会停止执行。
