# V8 场景更新三项优化结果

三项已分别实现并完成独立对照，最终采用GPU不可变几何共享。CPU数组缓存和固定槽位保留为可选实现。

## 三项独立结果

每行采用本轮自己的同期基线，比较完整规划RPC。

| 项目 | 基线平均 | 优化平均 | 累计耗时变化 | 处理结果 |
| --- | ---: | ---: | ---: | --- |
| CPU缓存 | 3.971秒 | 3.798秒 | 减少4.38% | CPU几何准备约减少51%，保留可选 |
| GPU几何共享 | 4.061秒 | 3.384秒 | 减少16.67% | 采用，进入完整对照 |
| 固定槽位 | 3.203秒 | 3.436秒 | 增加7.28% | 整场重装96→30次，保留可选 |

三个先导各20次请求，两组各10/10规划通过。三轮的抓法、选臂、关节与路径逐值相同，共180个终点和120条路径通过独立核验。

## 68场景完整对照

沿用原68个完整配对场景，136次请求全部完成，程序中断0，未执行0。优化组只开启GPU几何共享，两组均关闭CPU数组缓存和固定槽位。原两例指定右臂条件保持。

| 指标 | 当前内存更新基线 | GPU几何共享 |
| --- | ---: | ---: |
| 规划通过 | 67/68（98.53%） | 67/68（98.53%） |
| 完整RPC平均 | 4.336秒 | 3.524秒 |
| 完整RPC中位数 | 3.636秒 | 2.729秒 |
| 完整RPC P90 | 6.827秒 | 6.267秒 |
| 规划器与独立检查器场景更新 | 0.968秒 | 0.575秒 |
| 精细接触检查器场景更新 | 0.442秒 | 0.032秒 |
| 原生GPU网格创建 | 958次 | 342次 |

完整RPC累计减少18.72%，本轮68场景累计节省55.19秒。两项场景更新合计平均1.411→0.607秒。

两组检查候选均1088次，规划失败为同一场景。选中的抓法、手臂、关节解及预抓取和接近路径逐值相同；402个终点和268条路径通过独立核验。首次几何装载计入请求，正式几何从冷缓存开始，GPU2按原授权共享。
