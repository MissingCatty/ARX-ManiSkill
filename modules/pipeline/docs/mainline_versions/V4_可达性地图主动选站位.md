# V4：可达性地图主动选站位

## 当前结果

地图站位候选生成器已接入原生cuRobo终点检查与路径规划。苹果、桃子、锅铲三组同卡离线对照均通过，合计站位搜索从136.19秒降到21.99秒，减少83.9%。本轮新增物理抓取0次。

| 物体 | 几何站位搜索 | 地图主动搜索 | 耗时减少 | 两组规划结果 |
| --- | ---: | ---: | ---: | --- |
| 苹果 | 22.13秒 | 8.33秒 | 62.4% | 均通过 |
| 桃子 | 19.86秒 | 3.50秒 | 82.4% | 均通过 |
| 锅铲 | 94.21秒 | 10.16秒 | 89.2% | 均通过 |

两种搜索使用同一份移动前观测、原生候选池和RTX 4090，统一预热后计时，最多调用3次完整抓取规划。基线也使用双臂排名截断与批量开爪。实际优化策略与正式服务一致，为`interactive`；运行记录和每段优化报告均核对该配置。

当前活动注册表仍保留原入口，新地图方案通过独立模块供下一次新登记使用。原100例的88完整、1中断、11未开始及48次成功保留，原STOP保持。

## 规划多少自由度

cuRobo每次规划选中手臂的6个关节，夹爪单独控制。底盘XY、底盘转向和升降是前面的4个站位变量；选好站位并检查移动路径后，到位固定，再进行手臂轨迹规划。

整次站位搜索包含地图、几何检查、多次端点尝试和轨迹规划。下表单独记录一次求解接口调用的中位数，单位为毫秒；采用CUDA同步计时，包含CPU提交开销。

| 物体 | 预抓取等IK | 路径搜索 | 单段轨迹优化 |
| --- | ---: | ---: | ---: |
| 苹果 | 63.19 | 6.44 | 23.98 |
| 桃子 | 5.02 | 6.51 | 23.51 |
| 锅铲 | 30.81 | 7.28 | 33.67 |

抓取终点直接使用地图关节解，经过独立FK、实际限位与原生碰撞检查；预抓取和抬升仍使用原IK。上述单段时间与整次搜索时间分别保存，避免混用。[NVIDIA官方报告](https://research.nvidia.com/publication/2023-05_curobo-parallelized-collision-free-robot-motion-generation)给出的基准平均运动生成时间约53毫秒。

## 搜索方法

已有前方地图包含10559134组关节配置与完整TCP位姿。原来先组合几个固定站位，再逐个试抓法；现在保持原世界抓姿，取地图中的关节记录，反算能对齐该抓姿的底盘与升降位置。

| 步骤 | 具体做法 |
| --- | --- |
| 输入 | 使用头部感知得到的原生抓姿、实测机器人状态和RGB-D目标位置。 |
| 查询 | 按原排名每批查询16个抓姿，必要时向后查询，最多检查原排序前256个；完整输入池继续保留。 |
| 反算站位 | 分别求左右臂的底盘XY、朝向与升降高度。底盘移动不超过65厘米，转向在原±10°范围内，升降保留原限位和2毫米边界。 |
| 关节核验 | 完整机器人URDF独立FK，位置误差不超过2毫米、朝向误差不超过0.03弧度，并核对物理关节限位。 |
| 候选整理 | 每个抓姿每臂最多保留4个不同站位，先保持原模型排名，再比较移动、升降和关节变化。 |
| 碰桌快速检查 | 变换该关节解实际到达位姿下的原手掌与夹指网格；超出接触余量的明确碰撞提前排除。 |
| 原生端点门控 | 采用原871球、停放臂和V2指尖规则检查抓取终点，再检查原8厘米预抓取和3厘米抬升端点。 |
| 路径检查 | 检查原限速底盘与升降完整移动路径，再规划手臂到达与接近路径；已核验抓取关节解直接复用。 |
| 回退 | 地图方案没有通过时，剩余预算交给原几何站位与完整原候选池；两部分共用最多3次完整规划。 |
| 执行接线 | 通过的站位沿已检查路径移动，到位停稳后重新观测，再生成并规划最终抓姿。 |

地图缺项保持未知，原抓姿和评分保留。左右臂按实际肩部安装关系复用关节链，左臂为body4下Y方向50厘米平移。候选原点是TCP43、旋转沿用EEF轴；地图动作轴相对EEF绕Z转90°，查询前明确转换，输出再独立复算。

## V2指尖余量

沿用最前端10毫米与桌面上表面最多2毫米接触。原生终点门控、最终局部接近与闭合继续读取同一份配置。底盘移动路径保持原3毫米净空。

锅铲选中关节解的原生球模型与桌面有约4.19毫米重叠，实际网格核查指尖进入约1.24毫米，按V2规则通过。苹果和桃子选中终点的原生全世界检查直接通过。这里记录的是规划几何核查。

苹果和桃子均选中与基线相同的原始抓姿；锅铲通过调整站位使用原候选池的第56个抓姿，基线为第145个。三例均复用地图关节解，目标世界抓姿保持原输入。
