新实现绑定起始场景后，在每个原开度计算原生FK和871个碰撞球，再一起检查关节边界、自碰撞与场景碰撞。结束后恢复原规划状态。收爪也复用同一流程。

## 候选搜索后续可以优化的地方

1. 将固定场景和变化的夹爪开度分开更新。切换候选宽度时只更新锁定关节及相关运动学张量，避免再次绑定同一个场景；必须完整恢复IK、碰撞和轨迹上下文，并逐值核验。
2. 复用固定接触几何。URDF、碰撞网格和不变变换只准备一次，候选间只更新开度相关几何。
3. 对剩余候选的抓取IK单独比较固定批量检查。当前宽度各不相同，需要先保证每个候选使用自己的碰撞球和原搜索次序；不能将统一全开宽度的批量IK直接接过来。

这三项尚未执行。本次已完成的两项先保留为独立可选入口。
