## 结合实现分析

完整场景抓取IK的每请求平均耗时从2.812秒降到2.668秒，下降约5.12%。整次请求还包含绑定、预抓取、抬升、路径与记录交接，本轮这些环节的波动抵消了部分收益。

本次只省去了部分点的第三次射线查询，最近点搜索及原100轮优化配置继续执行。五批定位能确认离散碰撞查询占GPU内核时间97.75%，但最近点搜索与射线投票在该内核里的占比仍未分开。
