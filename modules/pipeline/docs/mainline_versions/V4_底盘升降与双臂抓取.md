# V4：底盘、升降与双臂抓取

V3在固定底盘、固定45.2厘米升降高度下选择左右臂。V4先根据头部观测选择底盘位置、朝向和升降高度，移动到位并停稳后重新拍摄，再让左右臂规划器选择一条臂抓取。

## 执行流程

| 步骤 | 实施方法 | 输出 |
| --- | --- | --- |
| 1. 远观目标 | 头部D405拍摄RGB-D，SAM3按目标名称生成掩码。反投影掩码内的有效深度，得到可见目标点的三维中位位置。 | 原图、深度、预测掩码、三维测量记录 |
| 2. 生成站位 | 根据目标相对body4的前后、左右、高度参考点，反推底盘XY、朝向和joint4升降值。候选受真实升降限位及65厘米最大移动距离约束。 | 站位候选、目标测量来源、候选代价 |
| 3. 检查移动与抓取 | 原机器人所有凸碰撞体检查底盘、升降移动路径；桌子和全部物体保留。按移动代价检查最多三个站位，并用同一组原生GraspGenX抓姿进行左右臂完整规划。 | 整机路径检查、左右臂规划、选中的站位 |
| 4. 移动并停稳 | 底盘沿平滑SE2路径移动，升降用原joint4的PD控制。双臂保持原姿态；到位后要求升降误差小于1毫米、全关节速度低于0.01且连续稳定0.5秒。 | 底盘与升降命令、实测轨迹、接触记录、移动视频 |
| 5. 到位后重新观测 | 重新拍摄头部RGB-D，重新运行SAM3、RaySt3R和GraspGenX。 | 新相机外参、新掩码、新点云、新抓姿 |
| 6. 选臂并抓取 | 两臂分别检查同一新候选池，按原生排名和关节位移选一臂。接近、闭合、基于实测闭合状态重新规划抬升并保持。 | 选臂依据、执行轨迹、双指接触与抓取视频 |
| 7. 独立核验 | 按原高度、保持、双指和禁止接触规则复核；分别统计感知失败、站位失败、规划不出来、实际抓取失败与未执行。 | 逐例评估、汇总与V4页面 |

## 底盘和升降如何执行

当前机器人资产中的三只轮子通过固定关节连接，未提供可驱动底盘的前后、左右、旋转关节。V4通过仿真根位姿接口按限速路径移动底盘，作为底盘控制接口；升降使用真实joint4的原驱动。底盘最高平移速度8厘米/秒，转速8度/秒，升降最高3厘米/秒。移动经过整机路径预检，执行时继续检查接触、双臂漂移、物体位移和停稳状态。

站位由目标观测和几何计算提出，完整抓取规划决定能否使用。原生抓取位姿保留世界坐标中的位置和朝向；站位计算改变机器人位置与高度。第一次粗观测的规划用于检查站位，到位后的实际抓取使用新观测与新规划。

## 场景与试验登记

本轮独立采样100个新场景，开阔、桌边、稀疏干扰、密集杂物、部分遮挡各20例，使用共享40类80型号资产库。普通目标的外轮廓距近侧桌沿10～26厘米，桌边组为8～10厘米；宽薄物体的遮挡场景预留20～40厘米，以容纳实际挡物。物体朝向连续随机。

构造只依据几何、落桌稳定性、头部视野和遮挡比例。先完成整组场景并散列冻结，再运行分割、点云、抓姿和IK。场景不按规划或抓取结果移动、替换。V3原200例与四条联调结果保留。

每个场景一次，共100槽。模型批前加载和预热、批内常驻；普通失败记录后继续。资源、配置、记录链故障或停稳无法确认时停止调度，保存故障现场和未执行数量。
