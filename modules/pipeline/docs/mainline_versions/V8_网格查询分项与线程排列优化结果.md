## 本次修改

原来相邻线程轮流检查多个障碍物，容量为8时，一组32个线程只处理4个球。现在让相邻线程处理同一个障碍物上的32个球，再继续下一个障碍物。所有球与障碍物组合都保留，最近表面搜索、三方向射线、距离公式和碰撞梯度沿用原代码；只改两个任务索引表达式。

这一排列方式让相邻线程访问相同网格，尝试减少分支分歧与不连续访存。方法依据见[NVIDIA CUDA编程优化指南](https://docs.nvidia.com/cuda/cuda-c-best-practices-guide/)。

两组共用NMS15与全部原候选后备、B16、C版YAML写出和原标量分支复核。两组完整IK分别预热并保留自己的CUDA Graph。
