# V8 细化NMS与解析端点完整规划对照

本轮把NMS从30毫米／30°调到15毫米／15°，在相同评分顺序下保留更细的抓法，再将GPU解析IK与批量碰撞接入完整规划的终点检查。

## 候选变化

69份已有观测沿用相同点云、宽深修正和硬筛结果，仅改变NMS阈值。每场景候选数中位数由54增加到151。所有输出姿态、宽度、评分和原始编号逐项核对；被NMS删除的候选不作为原始池后备。

## 第七项如何接入

1. 按双臂原16/64窗口取候选，同时生成抓取、预抓取和抬升三个原终点。
2. 使用固定256目标的常驻Graph求解析分支，并按各候选实际开度批量检查871球。
3. 保持评分顺序，选择离当前关节状态较近的合格分支，再用原独立FK和当前碰撞器复验。
4. 抓取终点保留V2真实网格检查，严格球模型碰桌不会提前删除可恢复的指尖接触。
5. 预抓取和抬升端点通过后，继续原完整路径和接近检查；解析方案失败，先在同一候选上尝试完整原方法，再推进下一候选。

每臂会话在启动预热时创建，直接复用原规划器的场景缓存。场景由原规划器更新，核对捕获张量地址不变；预检加入障碍后确认Graph能发现碰撞，再恢复原场景并逐项比对结果。
