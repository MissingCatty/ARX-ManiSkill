# 新主线实施方案

## 替换边界

SAM3 负责目标概念与实例掩码，RGB-D 反投影负责可见三维几何，GraspGenX 负责抓法生成、评分和候选接口。新链路以可见点云作为几何输入，形状补全差异单独评估，不调用 ZeroGrasp 作隐式补充。

规划与执行复用现有 cuRobo／ARX 能力。机器人、TCP43、碰撞与物理判据沿用明确登记的配置，感知替换不附带修改升降、底盘、碰撞球、GraspCL、MPC 或可达性投影。

## 输入与输出契约

每份观测绑定唯一帧标识，包含 RGB、对齐深度、深度到米的比例、图像尺寸、相机光学坐标内参和光学系到世界的变换。目标描述与 SAM3 预测记录引用同一帧，不借用旧腕部外参或旧实例掩码。

点云输出包含目标可见点、场景可见点、颜色、像素索引及坐标系标记。候选输出包含生成器位姿、原生评分、来源、夹爪条件版本及适配后的 ARX 位姿；每次筛选保存输入数量、输出数量和理由。

本轮静态观察已绑定传感器`head`、逐设备D405参数与45°向下安装配置。GraspGenX运行模式及候选预算、运动过程中的同步观察仍需在新主线联调登记中明确。候选生成不继承旧实验的30°俯抓限制。
