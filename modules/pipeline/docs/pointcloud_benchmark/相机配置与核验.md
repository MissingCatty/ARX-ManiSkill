# 相机配置与核验

本轮采用RealSense D405。项目实机采集脚本明确注明D405，并按序列号启动头部、左右腕部相机；ARX的数据采集资料也将头部和腕部列为D405。[ARX相机资料](https://arx-global.us/faq/)；[项目采集代码](../../../COOLAS-ARX/legacy/camera_data/get_rgbd.py)。当前GPU主机没有连接这些实机设备，型号采用已有项目和厂商记录，未新增现场设备识别。

同型号的不同实机具有各自的出厂标定，不能复制一组内参给所有相机。数据来自项目已有的`controllers.yaml`，本轮不重标定、不改写共享历史文件。

## 镜头、深度与模型输入

仿真器使用每台相机自己的RGB内参渲染，再按其镜头模型生成原始畸变图；原始深度按D405单位量化。进入被测模型前，RGB和对齐深度共用同一组映射去畸变，形成针孔输入；原始图、去畸变图和对应的两套参数均保留。模型输入标为零畸变，不能给去畸变图继续填写原始五个畸变系数。

D405默认每深度单位0.0001米，由[官方SDK实现](https://github.com/realsenseai/librealsense/blob/master/src/ds/d400/d400-device.cpp)确认。旧仿真统一输出的0.001米是应用编码，不应当作D405默认设备单位。模型若原生需要毫米或其他编码，适配端显式转换，原始数据不覆盖。将来接实机时仍须读取设备实际`get_depth_scale()`，避免把默认值当作设备当前设置。

厂家给出的理想工作区间是7–50厘米；50厘米不是硬截止距离。原始输出屏蔽小于7厘米的深度，应用远端上限分别保留头部2米、腕部1.5米并独立标注为应用策略；仿真可视渲染裁剪仍为0.05–10米，不混称深度量程。[D405厂家规格](https://www.realsenseai.com/products/stereo-depth-camera-d405/)

本轮对齐成像几何、标定和编码。深度来自渲染表面，尚未模拟真实双目匹配的噪声、反光缺失、曝光和运动模糊。评测因此反映仿真几何条件下的重建表现。

头部45°是本轮登记的安装设置，用于使相机朝向桌面，未声称这个角度已经通过实机手眼测量。旧相机的向前核查图及原外参继续保留。

![向下45°头部相机核查图](resources/head_camera.png)

本轮50例正式输入的目标区域深度中位数为0.30–0.40米。左腕部保留自身标定内参，其现有外参是镜像临时设置，未作为已实测手眼标定；本次模型输入仅使用头部。

## 已完成核验

使用官方`pyrealsense2`独立核对每台相机99个像素的反投影和81条射线的投影。三台相机最大反投影偏差小于1.5×10⁻⁷，最大投影偏差小于0.000066像素；深度单位、近端无效值、远端应用裁剪测试通过。头部和右腕部的仿真内参另与标定矩阵逐项核对，证据保存在`configs/camera_math_checks.json`和运行目录的`preflight.json`。

相关代码：`camera_imaging.py`、`check_camera_imaging.py`、`head_camera_config.py`。本轮无物理抓取动作。
