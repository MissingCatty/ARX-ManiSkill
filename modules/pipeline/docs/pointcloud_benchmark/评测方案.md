# 点云生成模型性能与效果评测

登记日期：2026年11月22日。网站实验版本为`pointcloud-models`，父版本为主线`sam3-graspgenx`。独立代码目录为`experiments/pointcloud_benchmark/`。

## 研究问题与边界

在相同ARX头部观测与SAM3目标掩码上，对比五种三维重建方法的几何误差、稳定生成耗时和常见物体不同款式的表现。本轮登记50个场景、每方法50次，共250项；不运行抓取候选、规划、物理抓取或训练。RGB-D直接反投影单列为可见表面参照，不计为第六种模型。

| 方法 | 原生输入 | 本轮输出与配置 | 准备状态 |
| --- | --- | --- | --- |
| RaySt3R | RGB、深度、目标掩码和内参 | 原生米制点云；5个预测视角，置信度阈值5，关闭TSDF | 权重完整，独立环境与接口预检通过 |
| Hunyuan3D-2mini-Turbo | 单张去背景RGB | 原生形状网格；5步、分辨率380、FlashVDM；不生成纹理 | 权重完整，官方样例接口预检通过；公共预热盘子的空网格保留 |
| Hunyuan3D-2-Turbo | 单张去背景RGB | 原生形状网格；5步、分辨率380、FlashVDM；不生成纹理 | 权重完整，接口预检通过 |
| SPAR3D | 单张去背景RGB | 32步512点条件点云及最终网格；只执行几何相关模块 | 权重完整，所有可学习几何参数核对与接口预检通过 |
| ZeroGrasp独立重建 | RGB、深度、目标掩码和内参 | 共享网络前向及八叉树重建解码，不生成抓取候选 | 复用已有权重，接口预检通过 |

RGB-only与RGB-D方法保留各自原生模态，不能解释为同输入的结构消融。ZeroGrasp仅为此离线实验的比较方法，不接回新主线。

## 场景和相机

| 条件 | 固定设置 |
| --- | --- |
| 类别 | 马克杯、水瓶、食品罐头、盒装食品、牛奶包装、番茄酱瓶、碗、苹果、勺子、剪刀 |
| 款式 | 每类5个现成RoboCasa/Objaverse资产，按模型目录选择，独立于被测模型的输出 |
| 场景 | 单物体、静态桌面、同位置与朝向，保留资产原尺寸；不执行机器人动作 |
| 相机 | 头部D405已有实机标定，640×480，新增45°向下俯角；历史共享外参不覆盖 |
| 成像 | 保存原始镜头畸变RGB与0.1毫米量化深度；模型共用去畸变针孔RGB-D |
| 目标掩码 | SAM3文本预测，阈值0.3；按预先列出的类别同义词及通用object后备提示，取首个非空提示中的最高分实例 |
| 真值 | 从实际渲染的可视网格取表面参考，仿真实例掩码仅用于独立打分 |

50个视觉资产按中心对齐后10微米量化顶点集核查，对应49组不同几何。C017与C020食品盒几何相同、外观不同，均保留；其余每类5款均有不同顶点集。预训练数据成员关系未知，因此这里衡量跨款式表现，不据此声称严格未见物体泛化。当前是50个新场景，不混用旧200例抓取的成绩。相机核对细节见[相机配置与核验](相机配置与核验.md)。

## 比较与指标

| 层次 | 方法 | 解释 |
| --- | --- | --- |
| 原生输出 | 保存完整网格、点云及中间条件点云 | 不用真值纠正模型原输出 |
| 统一点数 | 预测最多20,000点，网格按表面积采样；真值表面固定50,000点 | 所有被测方法使用相同预测预算，小点云不复制补点 |
| 部署米制几何 | RGB-D方法保留原生米制相机坐标；RGB-only方法只用共享预测掩码内的观测深度进行Sim(3)定标 | 24个正交旋转初始化、15轮ICP、保留85%对应点；定标耗时单列，不读取物体真值位姿或尺寸 |
| 完整表面 | 双向非平方最近点距离CD、2/5/10毫米精确率、覆盖率和F-score | CD中位数仅针对有效输出；F-score把正常空输出计0，故障和未执行另列 |
| 可见表面 | 可见深度点到预测的平均/P95距离 | 独立于隐藏表面补全能力 |
| 归一化形状 | 仅评分时独立归一化并对齐参考几何 | 不能把真值对齐分数当部署精度，变换不回流主结果 |
| 性能 | 加载、统一预热、常驻生成P50/P95、网格采样保存、观测定标及离线打分分开 | 所有正式方法依次使用同一物理GPU3；预检耗时不进入正式比较 |
