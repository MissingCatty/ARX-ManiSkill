# 代码与产物说明

项目根目录为`/home/zhaoyechong/projects/ARX-SAM3-GraspGenX/`。本轮代码、配置、运行数据和全部目录使用英文名，只有docs内的说明文档使用中文文件名。现有外部工程按其原路径引用，避免修改其他正在运行的工作。

## 目录

| 路径 | 内容 |
| --- | --- |
| configs/ | 新主线契约、逐设备D405参数、头部朝向与命名迁移记录 |
| third_party/ | 原始方法源码及固定Git版本 |
| weights/ | 本轮方法和辅助网络权重、来源与散列回执 |
| envs/reconstruction/ | RaySt3R与两种Hunyuan3D的隔离环境 |
| envs/spar3d/ | SPAR3D隔离环境 |
| experiments/pointcloud_benchmark/ | 实验准备、适配、执行及报告代码 |
| experiments/pointcloud_benchmark/runs/five_methods_50_20261122_01/ | 本轮冻结输入、250项登记和原始输出 |
| docs/pointcloud_benchmark/resources/ | 从真实输入和结果绘制的展示图 |

ZeroGrasp使用现有`tmp/arx-fullchain/env/`，SAM3使用现有`CLARO-ARX/.venv/`，捕获使用现有`ManiSkill/.venv/`。新环境通过只读路径复用已有PyTorch，不向共享环境安装或升级依赖。实际版本另存于运行目录的environment_snapshots。

## 代码职责

| 文件 | 作用 |
| --- | --- |
| camera_imaging.py / check_camera_imaging.py | D405畸变、深度编码、去畸变；与官方SDK独立核对 |
| head_camera_config.py / preflight_head_camera.py | 头部向下安装设置与实际渲染核查 |
| prepare_scenes.py | 筛选和派生资产、保存同帧RGB-D及独立评分参考 |
| segment_scenes.py | SAM3文本分割、按固定提示顺序选择实例并保存回执 |
| freeze_inputs.py | 先冻结输入及掩码散列，评分不回流选择 |
| model_adapters.py / spar3d_adapter.py | 方法原生输入输出适配，仅执行重建 |
| geometry_evaluation.py | 可见表面反投影、观测定标、CD/F-score和独立归一化形状评分 |
| warmup_model.py | 正式登记外的接口预检 |
| register_benchmark.py | 一次性登记代码、权重、输入、方法参数、资源和250项预算 |
| run_method.py | 单方法常驻、50例逐项保存；故障停止、不自动重试 |
| orchestrate_benchmark.py | 同GPU顺序运行五方法，记录等待、执行、完成或停止 |
| summarize_results.py | 只读已保存回执，生成汇总JSON、逐例CSV和中文结果文档 |
| visualize_results.py | 只读输入与点云，生成50例拼图、分布和固定案例图 |
| publish_progress.py | 将已有证据发布到现有本地进度网站，不启动模型或重跑试次 |

## 关键记录

| 文件或目录 | 含义 |
| --- | --- |
| registration.json / input_freeze.json | 正式登记与共享输入散列 |
| scene_selection.json / dataset_description.json | 款式索引、来源、尺寸、深度和几何重复核查 |
| observations/Cxxx/ | 原始/去畸变RGB、深度和对应相机参数 |
| segmentation_v03/Cxxx/ | 本轮实际使用的SAM3掩码、透明图、叠加与选择依据 |
| ground_truth/Cxxx/ | 独立评分几何、可见掩码、物体位姿；不进入模型输入 |
| methods/方法名/ready.json | 模型加载、公共预热和实际配置 |
| methods/方法名/Cxxx/ | 该项开始记录、原生输出、米制点云、指标和耗时 |
| methods/方法名/complete.json | 一个方法的50项完整回执 |
| STOP.json | 故障停止证据，保留并停止后续调度 |
| suite_complete.json | 五方法250项均保存后的完成记录 |
| source_snapshots/ | 固定源码版本、差异补丁和项目执行源码副本 |
| summary.json / case_metrics.csv | 汇总与逐项数值，未执行、空输出和运行故障分别统计 |

进度服务为`arx-pointcloud-benchmark-20261122-01.service`。它是本轮计算任务，不设置自动重启；现有网站仍由`claro-arx-progress.service`维护。已启动的正式登记不能重复调用执行入口来重跑。

重新生成报告与图不调用模型：

```bash
envs/reconstruction/bin/python experiments/pointcloud_benchmark/visualize_results.py
envs/reconstruction/bin/python experiments/pointcloud_benchmark/summarize_results.py
envs/reconstruction/bin/python experiments/pointcloud_benchmark/publish_progress.py --build
```

网站入口为`/iterations/pointcloud-models/`。拼图和三维对比采用缩略图按需加载，点击查看大图；完整点云不随网页自动下载。
