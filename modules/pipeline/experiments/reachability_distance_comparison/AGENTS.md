# 距离测试与可达性地图对照

- 用户要求将已完成的距离实验与现有机械臂可达性空间比对，检查高通过率位置是否位于地图更密集或位姿更匹配的区域。
- 只读使用11月21日冻结的前方纯运动学地图、53例×6档距离实验和独立三物体18位置对照。两批分别统计，不把重叠物体合并成独立样本。
- 地图坐标为body4/action_tcp43。候选池保存的朝向为实际EEF朝向，必须先还原EEF，再应用地图T_eef_action的90°工具轴旋转；位置均按实际body4世界变换对齐45.2厘米高度。
- 核对当前URDF、六轴关节限制、TCP43和独立FK。地图采样密度、位姿相近度、纯IK、无碰撞终点与完整初始轨迹分别比较，密度不写成校准后的成功概率。
- 位置统计覆盖全部817440个候选。连续位姿相近度每个原场景等距选64个原生排名，所有距离使用相同编号，同时查询G/H/L。原地图不加入本轮IK解。
- 只运行CPU分析，实际抓取、模型服务和新增IK调用均为0。已冻结地图和实验不修改。新代码及目录使用英文，中文报告放docs/diverse_grasp_benchmark/debug_20261123/。
